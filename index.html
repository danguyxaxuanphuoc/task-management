5. Trạng thái Kết nối & Hướng dẫn Triển khai

Hướng dẫn triển khai: 1. Đưa file HTML này lên GitHub Pages để chạy giao diện tĩnh.
2. Tạo Google Apps Script (GAS) backend để xử lý lưu công việc vào file Excel (.xlsx) trên Google Drive.
3. GAS cần triển khai endpoint RESTful, nhận dữ liệu JSON từ giao diện, xử lý lưu file Excel .xlsx.
4. Giao diện gọi GAS qua fetch API, cần cấu hình CORS và redirect phù hợp.
5. Không lưu khóa bí mật hay token trong HTML, bảo mật bằng OAuth hoặc xác thực riêng.
6. Phân biệt Google Sheets và file Excel (.xlsx): GAS có thể dùng Sheets làm trung gian, sau đó xuất XLSX cập nhật Drive.
7. Tích hợp trích xuất văn bản từ PDF/Word dùng thư viện JS (pdf.js, mammoth.js) để hỗ trợ điền tự động.
8. Lưu ý giới hạn đọc DOC cũ, PDF quét cần OCR ngoài phạm vi.
9. Quyền Drive cần cấp cho GAS để đọc/ghi file Excel.
10. Dịch vụ gửi email/Zalo cần cấu hình riêng, GAS chỉ gọi API gửi, không giả lập gửi.
11. Giao diện có chế độ trải nghiệm cục bộ, trạng thái kết nối rõ ràng.
12. Chống XSS khi hiển thị dữ liệu, không tự động thực thi nội dung tài liệu.

Mã Google Apps Script backend mẫu (copy & cấu hình URL endpoint):
// GAS: Code.gs
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    // Kiểm tra dữ liệu đầu vào
    if (!data.taskList) return ContentService.createTextOutput(JSON.stringify({error: "No taskList"})).setMimeType(ContentService.MimeType.JSON);

    // Mở hoặc tạo file Excel .xlsx trên Drive
    var folderId = "YOUR_FOLDER_ID"; // Thay bằng ID thư mục Drive
    var fileName = "DanhSachCongViec.xlsx";
    var folder = DriveApp.getFolderById(folderId);
    var files = folder.getFilesByName(fileName);
    var file;
    if (files.hasNext()) {
      file = files.next();
    } else {
      // Tạo file Excel mới (rỗng)
      var blob = Utilities.newBlob("", "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", fileName);
      file = folder.createFile(blob);
    }

    // Mở file bằng Sheets để chỉnh sửa (lưu ý: file Excel được chuyển sang Sheets)
    var ss = SpreadsheetApp.openById(file.getId());
    var sheet = ss.getSheetByName("CongViec");
    if (!sheet) sheet = ss.insertSheet("CongViec");
    sheet.clear();

    // Viết header
    var headers = ["Mã công việc", "Trích yếu", "Mã nhân sự", "Họ tên", "Số hiệu văn bản", "Thời điểm tạo", "Tên tệp đính kèm"];
    sheet.appendRow(headers);

    // Viết dữ liệu công việc
    data.taskList.forEach(function(task, i) {
      sheet.appendRow([
        task.taskId || "",
        task.summary || "",
        task.personnelId || "",
        task.personnelName || "",
        task.docNumber || "",
        task.createdAt || "",
        task.attachmentName || ""
      ]);
    });

    // Xuất file Sheets thành XLSX và ghi đè file gốc
    var xlsxBlob = ss.getBlob().setName(fileName);
    file.setContent(xlsxBlob.getBytes());

    return ContentService.createTextOutput(JSON.stringify({success: true})).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({error: err.message})).setMimeType(ContentService.MimeType.JSON);
  }
}

Lưu ý: Cần cấp quyền Drive cho GAS, cấu hình OAuth, và đảm bảo CORS cho phép gọi từ GitHub Pages.

Giới hạn và lưu ý bảo mật:
- Không lưu dữ liệu nhạy cảm trong thông báo hoặc kênh ngoài.
- Không tự động gửi email/Zalo khi chưa kết nối dịch vụ.
- Kiểm tra kỹ dữ liệu đầu vào, tránh XSS.
- PDF quét cần OCR ngoài phạm vi.
